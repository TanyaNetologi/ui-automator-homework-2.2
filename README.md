# Android UI Testing: UI Automator

## Описание проекта

Проект по автоматизации тестирования пользовательского интерфейса Android-приложения с использованием UI Automator.

Цель проекта: автоматизация проверки пользовательского ввода, обработки различных значений, взаимодействия с элементами интерфейса, перехода между экранами приложения и взаимодействия с системными настройками Android.

## Используемые технологии

- Kotlin — язык программирования.
- Android Studio — среда разработки.
- Android SDK 34 — инструменты разработки Android-приложений.
- UI Automator 2.3.0 — автоматизация взаимодействия с интерфейсом Android.
- JUnit 4.13.2 — организация и выполнение тестов.
- AndroidX Test — инструменты инструментального тестирования.
- Hamcrest 1.3 — проверка условий.
- Gradle — управление сборкой и зависимостями проекта.

## Объект тестирования

Android-приложение для проверки изменения текста, обработки пользовательского ввода и перехода между Activity.

Дополнительно проверяется взаимодействие с системным приложением Android Settings.

## Реализованные проверки

**1. Проверка изменения текста (testChangeText)**

- Запуск приложения.
- Ввод текста `Netology` в поле ввода.
- Нажатие кнопки изменения текста.
- Проверка соответствия отображаемого результата введённому значению.

**2. Проверка обработки пустого ввода (testEmptyText)**

- Проверка поведения приложения при вводе пустой строки.
- Проверка поведения приложения при вводе строки, состоящей из пробелов.
- Проверка сохранения первоначального текста при некорректном вводе.

**3. Проверка перехода между Activity (testOpenNewActivity)**

- Ввод текста в поле ввода.
- Нажатие кнопки перехода на новый экран.
- Проверка открытия второй Activity.
- Проверка передачи и отображения введённого текста на новом экране.

**4. Проверка системных настроек Android (testInternetSettings)**

- Запуск системного приложения Settings.
- Поиск элемента интерфейса по идентификатору ресурса.
- Выполнение нажатия на найденный элемент.

## Особенности автоматизации

В проекте используются возможности UI Automator:

- `UiDevice` — управление устройством и системными действиями.
- `By` — поиск элементов интерфейса.
- `UiSelector` — поиск элементов по заданным условиям.
- `Until` — ожидание появления элементов интерфейса.
- `ApplicationProvider` — получение контекста приложения.
- `InstrumentationRegistry` — доступ к инструментальному окружению.

Для синхронизации действий с интерфейсом используются ожидания с тайм-аутом 5000 мс.

## Запуск тестов

1. Открыть проект в Android Studio.
2. Дождаться завершения синхронизации Gradle.
3. Запустить Android Emulator или подключить Android-устройство с включённой отладкой по USB.
4. Выполнить запуск инструментальных тестов.

Запуск всех инструментальных тестов через терминал:

**Windows:**

```powershell
.\gradlew.bat connectedAndroidTest
```

**Linux / macOS:**

```bash
./gradlew connectedAndroidTest
```
